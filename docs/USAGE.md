# Android NAS Lite 使用与运维指南

本指南是 Android NAS Lite（以下简称 Lite 版）的官方标准说明书。Lite 版是 [完整版](https://github.com/styisme/android-nas) 的精简版本，移除了远程控制、Root 全盘、Web Shell、内网穿透、短信中心等高危或冗余功能，专注提供**稳定、干净的局域网文件服务**。

无论你是初次部署的小白，还是需要深度排查的极客，这里包含了从零安装、网络映射、五重安全防线配置、多端协同到故障排查的所有细节。

> **📌 当前文档版本：v4.5.0-lite.1**

---

## 第一章：服务端（Server）部署与调优

建议将服务端部署在一台屏幕完好（或碎屏但触控正常）的闲置 Android 手机上，并保持长期插电。

### 1.1 安装与基础权限授予
1. **安装应用**：前往本仓库 Actions 或 Releases 页面，下载最新的 `AndroidNAS-Server-v4.5.0-lite.1.apk`，安装到旧手机上。
2. **首次启动与权限**：首次打开 App 时，系统会要求“存储权限”和“通知权限”，务必点击允许，否则无法正常读取文件或维持后台服务。
3. **所有文件访问权限（Android 11+ 必做）**：首次启动会自动弹窗提示，点击前往设置并开启 `MANAGE_EXTERNAL_STORAGE`。如果不给这个权限，NAS 无法读取手机存储中的大多数文件。
4. **忽略电池优化**：弹出“后台保活提示”时，必须点击“去设置”并选择“允许”。若不小心点错，请去手机系统的 `设置 -> 应用管理 -> Android NAS Lite -> 电池 -> 设为“无限制”`。

> **📌 v4.5.0 权限变化**：Lite 版**未引入短信权限**（`RECEIVE_SMS` / `READ_SMS` / `SEND_SMS`），因为短信中心已从 Lite 版物理剔除。如果你安装了完整版，需注意完整版会请求这三项权限。

### 1.2 服务端驾驶舱
点击 App 右上角菜单，进入“NAS 驾驶舱”。**所有设置保存后都会自动重启服务以应用新配置**。
- **【基础】Tab**：修改设备名称；修改 Web (8080)、WebDAV (8081)、FTP (2121) 端口。
- **【服务】Tab**：一键开关网页流媒体、局域网剪贴板等增强功能。
- **【高级】Tab**：
  - **极寒省电模式**：降低 Wi-Fi 锁频率，适合只作为纯文件存储、无需流媒体播放的挂机场景。
  - **🛡️ 五重高级安全防线**：集中控制 2FA、隐藏入口暗号、算数验证码、局域网锁、防 CC 限流、会话超时、隐藏 Server 头。
  - **🔋 电池温度告警**：实时监控物理温度，超过 45℃ 触发 Webhook 报警。（**Lite 版无 Root 自动停充**）

### 1.3 账号体系与权限边界（v4.4.0 安全加固，v4.5.0 延续）
Lite 版移除了多用户管理 UI，底层 SQLite (`nas_core.db`) 仅保留两个预置账号：
- **Admin 账号**：默认账号密码 `admin / admin`。拥有 `WRITE_EXTERNAL_STORAGE` 范围内所有目录的读写权限。
- **Guest 账号**：默认账号密码 `guest / guest`。被底层路径拦截器严格锁定在 `/Public` 目录。

> **⚠️ v4.4.0 核心安全升级**：底层已引入 `ThreadLocal` 隔离与强制沙箱映射。即便在多用户高并发访问时，也绝对不会发生 A 用户串号看到 B 用户文件的情况；同时彻底封死了 `../` 目录穿越漏洞。
>
> **⚠️ v4.4.0-lite.2 沙箱回归修复**：`lite.1` 在精简时把 `safeFile()` 回退为 `new File(rootDir, path)` 的致命写法（Java `File` 构造器遇到绝对路径的第二个参数会忽略父目录），导致 `admin` / `guest` 全站 404 并伴随越权风险。`lite.2` 已恢复为强制 `replaceAll("^/+", "")` 后再拼接，`NasHttpServer` 与 `FtpServer` 同步修复。**v4.5.0-lite.1 保持该修复。**
>
> **注意**：Lite 版已移除全盘 Root 模式，`admin` 无法访问 `/data`、`/system` 等底层系统目录。

### 1.4 基础保活能力边界
Lite 版仅保留基础保活三件套：前台服务常驻通知 + `WakeLock`（CPU 锁）+ `WifiLock`（Wi-Fi 高性能锁）+ 开机自启。
在部分清理策略严苛的国产 ROM 上（如 MIUI、EMUI），服务仍可能被杀。遇到断连，请重新打开 App 或重启设备。

## 第二章：Web 网页端 (MD3) 与 PWA

网页端是零安装的最快入口。请在电脑或平板的浏览器中访问 `http://手机IP:8080`。

### 2.1 系统控制台与鉴权
- 若开启了密码验证，浏览器会弹出原生输入框，输入默认的 `admin/admin` 即可。
- **系统设置**：点击右上角 `⋮` 图标，选择 `⚙️ 系统设置`。你可以直接在网页上修改管理员密码、修改各类端口、开关 WebDAV/FTP/流媒体/剪贴板。
- **Webhook 推送配置**：在设置面板底部，你可以填入 Telegram 机器人或企业微信群机器人的 Webhook 地址。配置后，任何文件上传、温度报警、异常登录都会实时推送到你的设备。
- **五重安全防线面板**：在「系统设置 → 高级安全控制台」中，统一配置 2FA、隐藏暗号、算数验证码、局域网锁、防 CC 限流、会话超时、隐藏 Server 头。

### 2.2 PWA 渐进式应用
无需下载客户端，你的网页版就是原生的 App！
- 使用手机 Chrome 或 Edge 浏览器访问 `http://手机IP:8080`。
- 底部会自动弹出 **“添加到主屏幕”** 提示（或在浏览器菜单中手动点击“添加到主屏幕”）。
- 添加后，桌面会生成一个 NAS 图标。点击打开将全屏无地址栏运行，基于底层 `Service Worker`，支持部分离线静态资源的秒级加载。
- **v4.5.0 升级**：PWA 桌面图标与网页端菜单、顶部导航全部替换为 Material Symbols 矢量图标，告别 Emoji。

### 2.3 五重安全防线使用指南 (v4.5.0 全新实装)

五重防线**默认全部开启或关闭**的推荐配置如下：

| 防线 | 默认状态 | 建议 |
|---|---|---|
| 原生 2FA 两步验证 | 关闭 | 有公网穿透需求时**强烈建议开启** |
| 隐藏入口暗号 | 关闭 | 暴露在公网时**建议开启** |
| 算数图形验证码 | 开启 | 保持开启 |
| 高危 API 局域网锁 | 开启 | 保持开启，除非你只在内网使用 |
| 防 CC 限流 | 开启 | 保持开启 |

#### 2.3.1 原生 2FA 两步验证

1. 在网页端「系统设置 → 高级安全控制台」勾选「启用 2FA 保护」。
2. 前端会弹出密钥（如 `JBSWY3DPEHPK3PXP`），并**要求你输入一次当前 6 位验证码**（Lite 版加固：开启前强制验证，防锁死）。
3. 把密钥添加到 Google Authenticator / Microsoft Authenticator / 1Password，获取 6 位验证码后填入，点击确定。
4. 开启后，`admin` 账号每次登录都需要额外提供 `X-TOTP-Code`，前端会自动缓存验证码。

> **⚠️⚠️⚠️ 2FA 锁死风险（高危必读）**
>
> 开启 2FA 后，如果 Authenticator 手机丢失、数据被清除、密钥输错，**你将被永久锁死**。唯一补救方式是：
> - **物理接触服务端设备**，清除 App 应用数据（`nas_core.db` 会丢失，但存储文件不受影响）；
> - 或者用**同一局域网的其他设备**，在 App 内「NAS 驾驶舱 → 高级设置」关闭 2FA 开关。
>
> **强烈建议**：开启 2FA 前，把密钥抄写在纸质笔记本或加密 U 盘，不要只依赖单一手机。

#### 2.3.2 隐藏入口暗号

1. 在「高级安全控制台」的「隐藏入口暗号」输入框设置一个暗号（如 `mysecret`），保存。
2. 之后访问网页时，URL 必须带上 `?s=mysecret`，例如 `http://192.168.1.100:8080/?s=mysecret`。
3. 不带暗号的非 API 请求会直接返回伪装 `404 Not Found`，防扫站脚本探测。

> **⚠️ 暗号遗忘怎么办？**
>
> 如果忘记暗号，网页端会永远返回 404。补救方法：
> - 在手机端 App 内「NAS 驾驶舱 → 高级设置」清空「隐藏入口暗号」；
> - 或清除服务端 App 应用数据（会重置数据库）；
> - **或者在浏览器里直接访问 `http://手机IP:8080/api/list?path=/`**（API 接口不强制暗号，会走 Basic Auth）。

#### 2.3.3 算数图形验证码

- 触发条件：连续输错密码触发 Fail2Ban 后，前端自动弹出算数题（如 `3 + 5 = ?`）。
- 计算结果通过 `X-Captcha` Header 回传，服务端缓存校验通过后立即移除，防重放。
- 人类用户看到题目立刻能算出来，并发爆破脚本无法绕过。

#### 2.3.4 高危 API 局域网锁

- **机制**：`/api/settings`、`/api/password` 等核心接口强制校验来源 IP。`isLanIp()` 精准覆盖 `127.0.0.1`、`192.168.x.x`、`10.x.x.x`、`172.16.x.x ~ 172.31.x.x` 等 RFC1918 网段。
- **豁免**：`/api/list`、`/api/download`、`/api/upload` 等常规文件接口不受此锁约束，**公网穿透场景下仍可正常读写文件**。

> **⚠️ 局域网锁误杀怎么办？**
>
> 如果你在公网穿透（frp / ngrok / Cloudflare Tunnel）环境下，尝试修改设置、修改密码等敏感操作时被 403 拦截：
> - 用 SSH 隧道 / VPN 接入内网后操作；
> - 或在网页端「高级安全控制台」临时关闭「高危操作仅限局域网」开关（关闭后所有 IP 都能修改设置，**降低安全等级**）；
> - 或直接从手机端 App 的「NAS 驾驶舱」修改配置（App 内操作不走 HTTP，不受此锁约束）。

#### 2.3.5 防 CC 限流与会话防护

- **单 IP QPS 限流**：每秒超过 30 次请求直接熔断封禁 15 分钟。保护旧手机不被恶意刷流量卡死。
- **闲置自动登出**：默认 30 分钟无操作后自动清空 Token，需重新登录。可在设置面板调整或设为 0 关闭。
- **隐藏 Server 响应头**：`Server: SecureNAS` 伪装，防攻击者识别底层 NanoHTTPD 版本。

### 2.4 文件流转与高级工具
- **大文件秒传与断点续传**：前端自动计算 MD5（秒传）并切分 2MB 块传输。4.4.0 移除了错误的流拦截，彻底解决了传输中断问题。
- **多选流式打包下载**：在文件列表中多选文件，点击下载。服务端会实时将文件压成一个 ZIP 流推送到浏览器，不占用手机本地空间。
- **安全分享机制**：生成外链时，访问会绑定分享者的身份进行沙箱解析。有效期为可选项（1 小时 / 1 天 / 7 天 / 永久），由 `expire` 参数控制，缺省 24 小时。
  - **⚠️ 已知限制（v4.5.0-lite.1 仍未修）**：分享弹窗虽然仍有「提取码」输入框，但**服务端当前未实现提取码校验**，填了也会被忽略。请勿依赖该输入框来保护分享链接。该前后端不一致将在后续版本修复。
  - 前端图片/视频预览改用短效 Share Token 鉴权，彻底解决了原生标签无法带 Header 导致的预览黑屏问题。
- **在线解压与编辑**：支持 ZIP 在线解压；点击 `.txt`、`.json` 等文件，可直接在网页内呼出 MD3 编辑器，修改后保存写回（服务端会自动生成 `.bak_<时间戳>` 备份）。
- **流媒体与剪贴板**：支持 `Range` 拖动播放（底层已修复句柄泄漏）；点击右上角 `📋 剪贴板`，跨设备复制文本。

### 2.5 电池温度告警 (v4.5.0 新增)

- **机制**：服务端实时监听 `ACTION_BATTERY_CHANGED`，读取物理温度。超过 45℃ 触发 Webhook 报警（如「⚠️ 电池高温警告，当前温度 46.2℃」），降到 42℃ 以下自动解除。
- **Lite 版限制**：**Root 自动停充已物理剔除**。Lite 版无 Root 模块，无法自动切断充电，需根据 Webhook 告警**手动拔电**或移动设备到通风处。
- **建议**：旧手机长期挂机时放在通风位置，避免阳光直射或密闭机柜。

## 第三章：手机客户端 (Android Client)

手机客户端是你的随身控制中心。

### 3.1 局域网发现与连接
- 点击右上角的 🔍 图标，客户端会开启多线程并发探测 8080 端口，几秒内即可自动发现 NAS 并添加。
- 支持多协议：原生 JSON（极速）、WebDAV（通用）、FTP（兼容老旧设备）。

### 3.2 相册自动备份（增量比对）
1. 点击右上角菜单栏的 `相册自动备份`。
2. 首次使用会请求 `READ_MEDIA_IMAGES` 权限（Android 13+）。
3. **底层原理**：客户端先向服务端请求 `/Photos/` 目录的所有文件名，再与手机相册进行比对。只有 NAS 上没有的照片才会被上传。

### 3.3 分享外链与投屏
- **分享外链**：在文件列表菜单选择 **【分享外链】**，自动生成短链并直接调起系统分享面板。
- **一键投屏**：点击视频文件，选择“投屏到电视”，手机会通过 UDP 发送 Play 指令，电视端瞬间播放。

### 3.4 大文件上传
- 手机端上传超过 2MB 的文件会自动走 MD5 秒传 + 2MB 分片流式上传。
- **对 `content://` URI**（如相册、文档选择器返回的 URI）的分片上传，通过 `ContentResolver` 重开输入流，不再触发 `FileNotFoundException`。

### 3.5 2FA 登录
- 如果服务端开启了 2FA，手机客户端在首次登录时会提示输入 6 位验证码。
- 客户端会缓存验证码到本地，下次登录时自动携带。
- 若验证码错误，会返回 `401` 并提示重新输入。

## 第四章：桌面端 (Win/Linux)

Lite 版移除了 CLI 命令行端，但保留了纯原生 `Tkinter` 开发的扁平化桌面 GUI。

- **全局搜索与剪贴板**：顶部新增全局实时搜索框，以及局域网剪贴板同步弹窗。
- **一键复制外链**：选中文件点击底部按钮，短链会自动复制到电脑剪贴板。分享弹窗可选择有效期。
- **多选上传与编辑**：支持多选文件并发上传（内置 MD5 秒传与 2MB 分片），自带在线文本编辑与 ZIP 解压。
- **系统托盘**：关闭主窗口时会最小化到托盘（依赖 `pystray` 与 `pillow`）。

> 运行环境：Python 3.8+（需安装 `requests`、`pystray`、`pillow`，若需自行打包还需 `pyinstaller`）。直接执行 `python desktop/nas_client.py` 即可启动。

## 第五章：TV 电视端

TV 端专为老旧电视盒子打造。采用 Leanback 卡片流（4 列网格），使用遥控器移动时，卡片会呈现 **1.1 倍放大与高亮边框动画**。

- **协同接收**：内置虚拟键盘与搜索功能，支持接收手机端通过 UDP 下发的配置（自动填入 NAS 密码）与投屏指令。
- **已知限制**：TV 端的「影视墙」与「时光相册」入口仍会调用已从 Lite 版移除的 `/api/media/wall` 与 `/api/photos` 接口，会返回 `404`。请忽略这两个按钮，或等待后续版本下掉相关 UI。

## 第六章：网络与协议互通（映射到电脑）

### 6.1 WebDAV 映射（Windows）
1. 右键“此电脑” -> “映射网络驱动器”。
2. 文件夹填写：`http://手机IP:8081`。
3. 输入账号密码。之后你的手机就会出现在“此电脑”里。
> WebDAV 同样受 `safeFile` 沙箱约束，并会被 IP 白名单与 Fail2Ban 拦截。**WebDAV 协议不支持 2FA 动态码 Header**，开启 2FA 后 `admin` 账号的 WebDAV 连接会失败。若需同时使用 2FA 与 WebDAV，请改用 `guest` 账号，或在系统设置中临时关闭 2FA。

### 6.2 FTP 映射
1. 打开 Windows 资源管理器。
2. 在地址栏直接输入 `ftp://手机IP:2121`。
3. 回车，输入账号密码，即可进行拖拽传输。
> FTP 同样受 `safeFile` 沙箱约束与 IP 白名单拦截。**FTP 协议不支持 2FA**，同 WebDAV 的注意事项。

## 第七章：深度故障排查（Troubleshooting）

### 7.1 鉴权与登录问题

1. **浏览器访问提示 401 Unauthorized**：
   - 检查账号密码是否正确。如果修改过密码，请在网页端清空缓存或使用无痕模式重新登录。
2. **开启了 2FA 但无法登录，或换了新手机**：
   - 2FA 密钥丢失无法找回。补救方法：
     - **物理接触设备**，清除 App 应用数据（会重置数据库）；
     - 或**同一局域网的其他设备**，在 App 内「NAS 驾驶舱 → 高级设置」关闭 2FA。
3. **网页打开提示 404 Not Found**：
   - 是否开启了「隐藏入口暗号」？如果开启了，必须在 URL 后面手动加 `?s=你的暗号`。
   - 如果忘记暗号，补救方法见 [2.3.2 隐藏入口暗号](#232-隐藏入口暗号)。
4. **公网穿透下无法修改系统设置**：
   - 这是「高危 API 局域网锁」的预期行为。补救方法见 [2.3.4 高危 API 局域网锁](#234-高危-api-局域网锁)。

### 7.2 文件与权限问题

5. **Guest 账号无法查看某些文件 / 提示 403 Forbidden**：
   - 这是**绝对沙箱安全机制**。`guest` 的根目录被锁定在 `/Public`。请确保你要访问的文件物理位置在这个目录内，且不要尝试使用 `../` 跳出目录。
6. **所有账号都报 404 / 无法列出任何文件**：
   - 极大概率踩中了历史 `lite.1` 的沙箱回归 Bug（`safeFile` 未剥离前导斜杠）。请升级到 **v4.5.0-lite.1** 或更高版本。若已是最新版仍复现，请检查 `CHANGELOG.md` 顶部版本号是否同步、CI 产物是否为你正在运行的包。

### 7.3 上传与下载问题

7. **大文件上传到一半失败**：
   - 检查手机存储空间是否已满，或后台是否被系统冻结导致网络断开。
   - 若是 `content://` URI 上传失败，v4.4.0-lite.2 已修复 `ContentResolver` 重开流逻辑。
8. **分享链接没要提取码就打开了**：
   - **已知限制**：v4.5.0-lite.1 服务端仍未实现提取码校验，前端的输入框会被忽略。请勿依赖提取码保护分享链接，改用「短有效期」策略。
9. **Webhook 收不到通知**：
   - 检查 Webhook URL 是否为 Telegram / 企微格式，且 NAS 能访问外网。可在网页端点击「测试推送」验证。

### 7.4 协议与协同问题

10. **WebDAV / FTP 连接失败**：
    - 若开启了 2FA，`admin` 账号的 WebDAV / FTP 连接会因缺少 `X-TOTP-Code` 而失败。改用 `guest` 账号，或临时关闭 2FA。
    - 检查 IP 白名单是否拦截了你的 IP。
    - 检查 Fail2Ban 是否因多次错误尝试封禁了你的 IP（等待 15 分钟，或在 App 内清除封禁）。
11. **跨端投屏搜不到电视**：
    - 检查路由器是否开启了“AP 隔离”（导致 UDP 广播失败）。确认电视端 App 是否在后台被杀。

### 7.5 保活与性能问题

12. **App 被杀或局域网断连**：
    - Lite 版未包含激进保活功能。请去手机系统的 `设置 -> 应用管理 -> Android NAS Lite -> 电池`，确保设为“无限制”，并在多任务界面锁定该 App。
13. **电池高温告警频繁触发**：
    - 检查服务端手机是否放在通风处、是否阳光直射、是否密闭机柜。
    - Lite 版无 Root 自动停充，需**手动拔电**降温。
    - 如 Webhook 误报，可在网页端关闭温度告警（关闭 Webhook URL 即可）。

### 7.6 账号找回

14. **忘记管理员密码**：
    - 卸载并重装 App 会重置数据库（`nas_core.db`），账号密码恢复为默认的 `admin/admin`（但不会删除你手机存储里的文件）。
    - 若开启了「敏感操作安全码 (PIN)」又忘记 PIN，同样只能通过重装 App 重置。
