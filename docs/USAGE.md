# Android NAS Lite 使用与运维指南

本指南是 Android NAS Lite（以下简称 Lite 版）的官方标准说明书。Lite 版是 [完整版](https://github.com/styisme/android-nas) 的精简版本，移除了远程控制、Root 全盘、Web Shell、内网穿透等高危或冗余功能，专注提供**稳定、干净的局域网文件服务**。

无论你是初次部署的小白，还是需要深度排查的极客，这里包含了从零安装、网络映射、多端协同到故障排查的所有细节。

---

## 第一章：服务端（Server）部署与调优

建议将服务端部署在一台屏幕完好（或碎屏但触控正常）的闲置 Android 手机上，并保持长期插电。

### 1.1 安装与基础权限授予
1. **安装应用**：前往本仓库 Actions 或 Releases 页面，下载最新的 `AndroidNAS-Server-v4.4.0-lite.1.apk`，安装到旧手机上。
2. **首次启动与权限**：首次打开 App 时，系统会要求“存储权限”和“通知权限”，务必点击允许，否则无法正常读取文件或维持后台服务。
3. **所有文件访问权限（Android 11+ 必做）**：首次启动会自动弹窗提示，点击前往设置并开启 `MANAGE_EXTERNAL_STORAGE`。如果不给这个权限，NAS 无法读取手机存储中的大多数文件。
4. **忽略电池优化**：弹出“后台保活提示”时，必须点击“去设置”并选择“允许”。若不小心点错，请去手机系统的 `设置 -> 应用管理 -> Android NAS Lite -> 电池 -> 设为“无限制”`。

### 1.2 服务端驾驶舱
点击 App 右上角菜单，进入“NAS 驾驶舱”。**所有设置保存后都会自动重启服务以应用新配置**。
- **【基础】Tab**：修改设备名称；修改 Web (8080)、WebDAV (8081)、FTP (2121) 端口。
- **【服务】Tab**：一键开关网页流媒体、局域网剪贴板等增强功能。
- **【高级】Tab**：**极寒省电模式**。开启后，系统会降低 Wi-Fi 锁频率，适合只作为纯文件存储、无需流媒体播放的挂机场景。

### 1.3 账号体系与权限边界（v4.4.0 安全加固）
Lite 版移除了多用户管理 UI，底层 SQLite (`nas_core.db`) 仅保留两个预置账号：
- **Admin 账号**：默认账号密码 `admin / admin`。拥有 `WRITE_EXTERNAL_STORAGE` 范围内所有目录的读写权限。
- **Guest 账号**：默认账号密码 `guest / guest`。被底层路径拦截器严格锁定在 `/Public` 目录。

> **⚠️ v4.4.0 核心安全升级**：底层已引入 `ThreadLocal` 隔离与强制沙箱映射。即便在多用户高并发访问时，也绝对不会发生 A 用户串号看到 B 用户文件的情况；同时彻底封死了 `../` 目录穿越漏洞。
> **注意**：Lite 版已移除全盘 Root 模式，`admin` 无法访问 `/data`、`/system` 等底层系统目录。

### 1.4 基础保活能力边界
Lite 版仅保留基础保活三件套：前台服务常驻通知 + `WakeLock`（CPU 锁）+ `WifiLock`（Wi-Fi 高性能锁）+ 开机自启。
在部分清理策略严苛的国产 ROM 上（如 MIUI、EMUI），服务仍可能被杀。遇到断连，请重新打开 App 或重启设备。

## 第二章：Web 网页端 (MD3) 与 PWA

网页端是零安装的最快入口。请在电脑或平板的浏览器中访问 `http://手机IP:8080`。

### 2.1 系统控制台与鉴权
- 若开启了密码验证，浏览器会弹出原生输入框，输入默认的 `admin/admin` 即可。
- **系统设置**：点击右上角 `⋮` 图标，选择 `⚙️ 系统设置`。你可以直接在网页上修改管理员密码、修改各类端口、开关 WebDAV/FTP/流媒体/剪贴板。
- **Webhook 推送配置**：在设置面板底部，你可以填入 Telegram 机器人或企业微信群机器人的 Webhook 地址。配置后，任何文件上传或异常都会实时推送到你的设备。

### 2.2 PWA 渐进式应用 (v4.4.0 全新体验)
无需下载客户端，你的网页版就是原生的 App！
- 使用手机 Chrome 或 Edge 浏览器访问 `http://手机IP:8080`。
- 底部会自动弹出 **“添加到主屏幕”** 提示（或在浏览器菜单中手动点击“添加到主屏幕”）。
- 添加后，桌面会生成一个 NAS 图标。点击打开将全屏无地址栏运行，基于底层 `Service Worker`，支持部分离线静态资源的秒级加载。

### 2.3 文件流转与高级工具
- **大文件秒传与断点续传 (v4.4.0 修复增强)**：在网页端上传大文件时，前端会自动计算 MD5（秒传）并切分 2MB 块传输。4.4.0 移除了错误的流拦截，彻底解决了之前版本偶尔出现的传输中断问题。
- **多选流式打包下载**：在文件列表中多选文件，点击下载。服务端会实时将文件压成一个 ZIP 流推送到浏览器，不占用手机本地空间。
- **安全分享机制**：生成免密外链时，访问会绑定分享者的身份。此外，v4.4.0 重写了前端的图片/视频预览逻辑，改用短效 Share Token 鉴权，彻底解决了原生标签无法带 Header 导致的预览黑屏问题。
- **在线解压与编辑**：支持 ZIP 在线解压；点击 `.txt`、`.json` 等文件，可直接在网页内呼出 MD3 编辑器，修改后保存写回。
- **流媒体与剪贴板**：支持 `Range` 拖动播放（底层已修复句柄泄漏）；点击右上角 `📋 剪贴板`，跨设备复制文本。

## 第三章：手机客户端 (Android Client)

手机客户端是你的随身控制中心。

### 3.1 局域网发现与连接
- 点击右上角的 🔍 图标，客户端会开启多线程并发探测 8080 端口，几秒内即可自动发现 NAS 并添加。
- 支持多协议：原生 JSON（极速）、WebDAV（通用）、FTP（兼容老旧设备）。

### 3.2 相册自动备份（增量比对）
1. 点击右上角菜单栏的 `相册自动备份`。
2. 首次使用会请求 `READ_MEDIA_IMAGES` 权限（Android 13+）。
3. **底层原理**：客户端先向服务端请求 `/Photos/` 目录的所有文件名，再与手机相册进行比对。只有 NAS 上没有的照片才会被上传。

### 3.3 分享外链与投屏
- **分享外链**：在文件列表菜单选择 **【分享外链】**，自动生成免密短链并直接调起系统分享面板。
- **一键投屏**：点击视频文件，选择“投屏到电视”，手机会通过 UDP 发送 Play 指令，电视端瞬间播放。

## 第四章：桌面端 (Win/Linux)

Lite 版移除了 CLI 命令行端，但保留了纯原生 `Tkinter` 开发的扁平化桌面 GUI。

- **全局搜索与剪贴板**：顶部新增全局实时搜索框，以及局域网剪贴板同步弹窗。
- **一键复制外链**：选中文件点击底部按钮，免密短链会自动复制到电脑剪贴板。
- **多选上传与编辑**：支持多选文件并发上传，自带在线文本编辑与 ZIP 解压。

> 运行环境：Python 3.8+（需安装 `requests`，若需自行打包还需 `pyinstaller`）。直接执行 `python desktop/nas_client.py` 即可启动。

## 第五章：TV 电视端

TV 端专为老旧电视盒子打造。采用 Leanback 卡片流（4 列网格），使用遥控器移动时，卡片会呈现 **1.1 倍放大与高亮边框动画**。

- **协同接收**：内置虚拟键盘与搜索功能，支持接收手机端通过 UDP 下发的配置（自动填入 NAS 密码）与投屏指令。

## 第六章：网络与协议互通（映射到电脑）

### 6.1 WebDAV 映射（Windows）
1. 右键“此电脑” -> “映射网络驱动器”。
2. 文件夹填写：`http://手机IP:8081`。
3. 输入账号密码。之后你的手机就会出现在“此电脑”里。

### 6.2 FTP 映射
1. 打开 Windows 资源管理器。
2. 在地址栏直接输入 `ftp://手机IP:2121`。
3. 回车，输入账号密码，即可进行拖拽传输。

## 第七章：深度故障排查（Troubleshooting）

1. **浏览器访问提示 401 Unauthorized**：
   - 检查输入的账号密码是否正确。如果修改过密码，请在网页端清空缓存或使用无痕模式重新登录。*(注：v4.4.0 已彻底修复了密码输错时无限弹窗死锁的 Bug)*。
2. **Guest 账号无法查看某些文件 / 提示 403 Forbidden**：
   - 这是 v4.4.0 的**绝对沙箱安全机制**。`guest` 的根目录被底层强制剥离前导斜杠并锁定在 `/Public`。请确保你要访问的文件物理位置在这个目录内，且不要尝试使用 `../` 跳出目录。
3. **大文件上传到一半失败**：
   - v4.4.0 已经修复了分片上传的流处理问题。如果依然失败，请检查手机存储空间是否已满，或后台是否被系统冻结导致网络断开。
4. **跨端投屏搜不到电视**：
   - 检查路由器是否开启了“AP 隔离”（导致 UDP 广播失败）。确认电视端 App 是否在后台被杀。
5. **App 被杀或局域网断连**：
   - Lite 版未包含激进保活功能。请去手机系统的 `设置 -> 应用管理 -> Android NAS Lite -> 电池`，确保设为“无限制”，并在多任务界面锁定该 App。
6. **忘记管理员密码**：
   - 卸载并重装 App 会重置数据库（`nas_core.db`），账号密码恢复为默认的 `admin/admin`（但不会删除你手机存储里的文件）。
